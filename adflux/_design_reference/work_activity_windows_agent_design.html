Shown once after install. Cannot be skipped. The agent does nothing until they accept.

6. Data structure

All new tables are written by the agent through database functions only. Clients read nothing directly.

TableHolds
work_agent_devicesperson, PC name, agent version, last seen, consent accepted at
work_activity_slicesperson, time entry, start, program, window title, active seconds, idle seconds (one row per minute of work)
work_screenshotsperson, time entry, taken at, storage path (private bucket), size
work_tracking_settingsinterval, retention days, per-person on / off

Access: admin and heads read; a person reads only their own. Cron deletes screenshots after the retention period. Screenshots live in a private storage bucket, opened through short-lived links.

7. Build order

  1. Tables, storage bucket, functions, retention cron (SQL).
  2. Activity tab and Settings in Team Work (works with test data).
  3. Windows agent: consent, timer, program and window capture, idle, screenshots, upload. Signed installer.
  4. Pilot on one PC for a week, then roll out to all PCs before 30 Nov.
