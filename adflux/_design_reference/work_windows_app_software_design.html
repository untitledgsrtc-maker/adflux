Untitled Work for Windows

Software design: how the program itself is built and behaves, not a page list. For approval; nothing built. Unsigned installer accepted by owner (15 Oct 2026). First tracked person: Safika; more added later.

1. What the program is

ItemDecision
NameUntitled Work
Runs onWindows 10 and 11 (64-bit)
Built withTauri (small, about 10 MB, low memory). Same login as the web app.
InstallerOne UntitledWork-Setup.exe, not signed. Windows shows "Windows protected your PC": click More info, then Run anyway (one time per PC).
StartStarts with Windows, lives in the system tray (bottom right), main window opens on click.
UpdatesChecks for a new version at start and once a day, installs on next launch. Updates are verified with our own key even though the installer is unsigned.
OfflineKeeps recording while offline, uploads when the internet is back (up to 48 hours stored).
Data it sendsTimer start / stop, active program name, window title, idle seconds, screenshots (every 10 min, only while a timer runs). Nothing else. No keystrokes, no mouse positions, no file contents.

6. How it connects to the system

PieceHow
TimerSame work_* functions the website uses, so web, app and Team Work always agree.
Activity and idleBatched every minute to work_activity_slices and work_idle_events.
ScreenshotsPrivate storage bucket, uploaded with a short-lived link. Row in work_screenshots.
Who is trackedPer-person on / off in work_tracking_settings. First: Safika. The program only records when its person is switched on.
Who sees itAdmin and team head, in Team Work, new Activity tab.
Consent recordAccept stored with time and PC name in work_agent_devices.
